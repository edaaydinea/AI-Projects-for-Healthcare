# AI-Projects-for-Healthcare

This repository contains a curated collection of **Artificial Intelligence, Machine Learning, Data Science, and Computer Vision projects** focused on healthcare applications.  
The projects range from educational implementations to applied research studies in medical imaging, clinical data analysis, and cognitive neuroscience.

## Projects in Bootcamp Education

- **[Breast Cancer Classification ✅](https://github.com/edaaydinea/AI-Projects-for-Healthcare/blob/master/Breast%20Cancer%20Classification/Breast_Cancer_Classification.ipynb)**  
  Classification of breast tumors as malignant or benign using classical machine learning techniques.

- **[Detecting COVID-19 with Chest X-ray using PyTorch ✅](https://github.com/edaaydinea/AI-Projects-for-Healthcare/blob/master/Detecting%20COVID-19%20with%20Chest%20X-Ray%20using%20PyTorch/Detecting%20COVID-19%20with%20Chest%20X-Ray%20using%20PyTorch.ipynb)**  
  Detection of COVID-19 from chest X-ray images using PyTorch.  
  Dataset: [Kaggle – COVID-19 Radiography Database](https://www.kaggle.com/datasets/tawsifurrahman/covid19-radiography-database)

- **[Diabetes Prediction with PySpark MLLIB ✅](https://github.com/edaaydinea/AI-Projects-for-Healthcare/blob/master/Diabetes%20Prediction%20With%20Pyspark%20MLLIB/Diabetes_Prediction.ipynb)**  
  Logistic regression model built with PySpark MLLIB to classify patients as diabetic or non-diabetic.  
  Guided project: [Coursera](https://www.coursera.org/projects/diabetes-prediction-with-pyspark-mllib)

- **[Heart Failure Data Analysis ✅](https://jovian.ai/edaaydinea/health-failure-prediction)**  
  Exploratory data analysis of the Heart Failure Prediction dataset using Plotly.  
  Dataset: [Kaggle – Heart Failure Clinical Data](https://www.kaggle.com/datasets/andrewmvd/heart-failure-clinical-data)

- **[Relationship between COVID-19 & Happiness Across Countries ✅](https://github.com/edaaydinea/AI-Projects-for-Healthcare/blob/master/Relationship%20between%20COVID-19%20%26%20Happiness%20in%20that%20Country/covid19%20data%20analysis%20notebook.ipynb)**  
  Analysis of the relationship between COVID-19 spread and national happiness levels.  
  Datasets: Johns Hopkins University COVID-19 data and World Happiness Report.

## Research Projects

The following projects are maintained in **separate repositories** and represent applied or research-oriented work:

- **[Chest X-Ray Image Classification (Pneumonia) ✅](https://github.com/edaaydinea/Chest-Xray-Image-Classification-by-using-PyTorch-CNN)**  
  CNN-based pneumonia detection on pediatric chest X-ray images using PyTorch.

- **[Pneumonia Detection on Chest X-ray Images (Keras) ✅](https://github.com/edaaydinea/Pneumonia-Detection-on-Chest-Xray-Images-with-Deep-Leaning)**  
  Deep learning–based pneumonia detection using Keras/TensorFlow.

- **[COVID-19 ICU Admission Probability Estimation ✅](https://github.com/edaaydinea/Estimating-the-Probability-of-Confirmed-COVID-19-Cases-Taking-into-the-Intensive-Care-Unit-ICU)**  
  Estimation of ICU admission probability for confirmed COVID-19 patients using predictive modeling.

- **[Alzheimer’s Disease Progression Prediction (OP1) ✅](https://github.com/edaaydinea/OP1-Prediction-of-the-Different-Progressive-Levels-of-Alzheimer-s-Disease)**  
  Prediction of progressive stages of Alzheimer’s disease using clinical data.

- **[Alzheimer’s Disease Progression Prediction with MRI (OP2) ✅](https://github.com/edaaydinea/OP2-Prediction-of-the-Different-Progressive-Levels-of-Alzheimer-s-Disease-with-MRI-data)**  
  Prediction of Alzheimer’s disease stages using MRI-based features.

- **[Low Grade Glioma Segmentation ✅](https://github.com/edaaydinea/Low-Grade-Glioma-Segmentation)**  
  Segmentation of low-grade gliomas from brain MRI scans using deep learning.

- **[Optimization of Human Sensory Neuron Differentiation for Pain Research ✅](https://github.com/edaaydinea/LifeArc_BiologyResearch)**  
  Research project conducted at LifeArc focusing on in vitro human sensory neuron differentiation for analgesic drug testing.

- **[Distinguishing Cognitive Reading States using Advanced NLP and Transformers ✅](https://github.com/edaaydinea/LLMAnalysisCognitiveStates)**  
  Differentiation of cognitive reading states (Normal Reading vs. Task-Specific Reading) using NLP and transformer-based models on the ZuCo dataset.
